# Supply Chain Demand Forecasting

This repository contains code and assets for supply chain demand forecasting experiments and applications.

Structure created by automation. Populate the folders as you develop the project:

- data/: raw, processed, and external datasets
- notebooks/: exploratory analysis and experiments
- src/: source code and modules
- sql/: SQL scripts and queries
- models/: trained model artifacts
- dashboard/: dashboard app and assets
- reports/: papers and reports
- app/: production application code
- docs/: project documentation
